# Visual system

The SOC console is an operator workspace. Deep blue slate surrounds a lighter central work surface. Mineral teal identifies the current location and primary action; amber and red are reserved for warning and critical state. Text uses the system sans for fast scanning, with tabular numerals for data.

Navigation is a persistent, compact rail on desktop and a wrapped route list on narrow screens. Content uses a 12-column grid, clear section headings, table rows with firm separators, and a shared vocabulary for badges and controls. The distinctive element is the investigation timeline: a narrow connected track linking each recorded piece of evidence and action in time. It is functional, not decorative.

No dashboard value is invented to fill a blank state. Loading, empty, error and unknown each have distinct treatments. Simulated integrations and actions carry the DEMO label.
